# SFMono-NF

[返回软件清单](../README.md)

Apple SF Mono 字体 + Nerd Fonts 补丁，上游为 [epk/SF-Mono-Nerd-Font](https://github.com/epk/SF-Mono-Nerd-Font)，manifest 标记为 MIT。

## 安装与更新

Windows 10 1809+ 和 Windows 11 默认安装到当前用户，无需管理员权限。

```powershell
scoop install lz-bucket/SFMono-NF
scoop update SFMono-NF
scoop uninstall SFMono-NF
```

全局安装、旧版迁移、卸载占用排查和回归测试见[字体共用说明](fonts.md)。Windows 10 1809 之前需要全局安装。
